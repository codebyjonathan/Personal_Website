# Jonathan Alfaro - Personal Website

A responsive, bilingual personal website starter built with plain HTML, CSS, and JavaScript. It is designed to work as a static site and can be published with GitHub Pages.

## Preview

Open `index.html` in a browser. The English / Spanish controls switch the page language, and the navigation links jump to each section.

## Next content steps

Replace the starter copy with Jonathan's notes and materials. Useful items to gather are a short introduction, personal story, current focus, projects or community work, profile links, and a portrait if one should appear on the site.

## Publish with GitHub Pages

Push the repository to GitHub, then select **Settings > Pages** and publish from the `main` branch root. The site entry point is `index.html`.
