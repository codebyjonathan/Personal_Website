# Jonathan Alfaro - Personal Website

A responsive, bilingual portfolio built with plain HTML, CSS, and JavaScript. It highlights Jonathan's software, robotics, community, and STEM work, with links to selected projects and professional profiles.

## Preview

Open `index.html` in a browser. Use the English / Spanish controls to switch languages, and the navigation links to jump between sections.

## Publish with GitHub Pages

In the repository, select **Settings > Pages** and publish from the `main` branch root. The site entry point is `index.html`.
